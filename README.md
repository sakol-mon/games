# Game for Outcome-Base Education Project

A Private Live score and Environment Games System with an integrated Score. Designed to enhance interactive event engagement and environmental education.

## Features
- **Multiple Environmental Mini-Games**: Includes interactive games about renewable energy, water conservation, waste sorting, upcycling, and eco-friendly choices.
- **Integrated Score & Leaderboard System**: Supports score tracking, player names, and leaderboard displays for selected games.
- **Config-Driven Content**: Questions, cards, images, and scoring rules are stored in JSON files for easy updates and customization.
- **Browser-Based Game Hub**: A central landing page lets players choose a game and start playing directly in the browser.
- **Responsive Educational UI**: Designed for classroom, workshop, and event-based learning activities.
